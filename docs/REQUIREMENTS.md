# 人生シミュレーター 要件定義（たたき台）

Oct 25, 2026 · @jp39052900

## コンセプトと決定事項

生まれ・職業・価値観の違う人の一生を、お金と幸福度の両面でシミュレートするWebゲーム。軸は「正解の人生はない」で、同じ年収でも価値観が違えば幸福度が変わる。

| 項目 | 決定 |
| --- | --- |
| ゴール | 資産だけでなく幸福度も評価する |
| トーン | リアル寄り。税・社会保険・物価・景気も計算 |
| 用途 | 配信ネタ優先、面白ければ一般公開 |
| 期間 | 社会人スタート(学歴により15〜22歳)から死亡まで |
| 時間単位 | 1ターン=1ヶ月、年末に年間サマリー |
| 操作 | 数年単位の方針でオート進行、方針はいつでも変更可 |
| 価値観 | プレイヤーが選ぶ |
| 社長 | 初期ガチャには出さず、起業イベント経由 |
| 死亡 | 年齢・健康・行動によるランダム |
| イベント | ランダム発生、選択肢つき |
| 世代継承 | 入れる。子どもが遺産を継いで次の人生へ |
| 見た目 | まずテキストとグラフ。UIに凝るのは次の段階 |

## ゲームの流れ

1ターン=1ヶ月。プレイヤーは数年単位の方針(働き方・支出・投資・健康)を決めてオートで進め、方針はいつでも変えられる。イベントや重要な分岐のときだけ止まる。

方針の選択肢:

| 方針 | 選択肢 |
| --- | --- |
| 働き方 | 定時 / 普通 / 残業多め / 激務 |
| 支出 | 節約 / 普通 / ゆとり / 浪費 |
| 投資 | 預金のみ / 積立(インデックス) / 個別株 / 信用取引・仮想通貨 |
| 健康 | 気にしない / 普通 / 意識高め |

年末には年間サマリーを挟み、配信ではここを区切りにする。表示するのは年齢と経過年数、健康状態、金融資産とその前年からの増減。

倍速やスキップ(「何もなければ次のイベントまで飛ばす」)を入れれば、1ヶ月単位でも配信尺に収まる。

イベント判定で止まるとき以外はオートで回り、死亡判定に引っかかった時点で一生が終わる。

## パラメータ設計

パラメータは「初期ガチャ」「価値観」「隠しステータス」の3層。価値観を入れるのがこのゲームの肝で、人によって歩み方が変わる理由になる。

### 初期ガチャ(生まれた時点で決まる)

| パラメータ | 内容 | ゲームへの影響 |
| --- | --- | --- |
| 学歴 | 中卒・高卒・専門卒・大卒(就ける職業の制限はなし) | 開始年齢(15/18/20/22歳)、初任給、奨学金の有無 |
| 職業 | 営業・事務・エンジニア・バイトなど(社長は起業イベントでのみなれる) | 給与水準、昇給カーブ、残業、リストラ率 |
| 実家の太さ | 5段階(太い〜実家が借金持ち) | 仕送り、相続、親の介護負担 |
| 初期資産 | 貯金・奨学金などの借金 | スタート時の余裕 |
| 体質 | 健康の初期値と病気のなりやすさ | 寿命、医療費 |
| 運 | 隠し値 | イベントの当たり外れ |

### 価値観(幸福度の感じ方を決める)

価値観はスタート時にプレイヤーが選ぶ。その後はイベントでの選択によって少しずつ変化する。

| 軸 | 片方の極 | もう片方の極 |
| --- | --- | --- |
| リスク | 安定志向 | 挑戦志向 |
| 人間関係 | 家族重視 | 自由・独身志向 |
| お金の使い方 | 貯める派 | 使う派(物欲・体験) |
| 仕事 | 生活のため | やりがい・出世 |

### 隠しステータス(毎月変動)

- 健康: 病気・死亡率に直結。過労や不摂生で下がる
- ストレス: 高いと健康低下、浪費、離婚などを誘発
- スキル: 昇進・転職・副業の成功率
- 信用: ローン審査、起業、詐欺の被害に影響
- 人間関係: 結婚、友人からの助け、孤独

## 幸福度の仕組み

毎月の幸福度は、6つの要素の満たされ具合に価値観で重みをつけて合計する。家族重視の人は結婚・子育てで大きく上がり、自由志向の人は自由時間で上がる。

```latex
\text{幸福度} = \sum_{i} w_i(\text{価値観}) \times s_i(\text{状態})
```

| 要素 | 満たされる条件 |
| --- | --- |
| 生活水準 | 収入と支出のバランス |
| 安心 | 貯蓄、保険、雇用の安定 |
| 人間関係 | 家族、友人、パートナー |
| 自由時間 | 残業の少なさ、趣味 |
| 健康 | 健康ステータス |
| 達成感 | 昇進、起業成功、資産目標 |

リアル寄りにするため、次の2つを入れる。

- 頭打ち: 年収が一定を超えると生活水準の幸福度はほとんど増えない
- 慣れ: 生活水準を上げると、その状態が当たり前になって幸福度が徐々に戻る。下げたときは大きく下がる

死亡時のリザルトでは「生涯幸福度」と「最終資産・遺産」を並べて表示し、両方からタイプ判定をする(例: 金持ち不幸型、貧乏だけど幸せ型)。

## お金のリアル要素

日本の制度をベースに、数字はリアルに寄せつつ計算は簡略化する。MVPでは手取り率の近似で済ませ、細かい税計算は後回しにする。

| 分類 | 内容 | MVP |
| --- | --- | --- |
| 収入 | 給与(額面と手取り)、ボーナス、副業、退職金 | ○ |
| 税・社保 | 所得税・住民税・社会保険料(手取り率で近似) | ○(近似) |
| 支出 | 生活費、家賃、教育費、医療費 | ○ |
| 投資 | 預金、インデックス、個別株、信用取引、仮想通貨、不動産 | 一部 |
| 借入 | 奨学金、住宅ローン、カードローン | 一部 |
| 保険 | 加入すると病気・事故時の出費が減る | 後 |
| 老後 | 年金受給、資産の取り崩し | ○ |
| 景気 | 好景気・不況・暴落のサイクル、インフレ | 後 |
| 相続 | 親からの相続、自分の遺産 | 後 |

## 死亡判定

毎ターン、年齢別の基本死亡率に健康と行動の補正をかけて判定する。基本死亡率は生命表に寄せ、何もしなければ平均寿命前後で死ぬバランスにする。

```latex
\text{死亡確率} = \text{基本死亡率}(\text{年齢}) \times \text{健康補正} \times \text{行動補正}
```

| 死因 | 上がる条件 |
| --- | --- |
| 病気 | 加齢、健康低下、ストレス、体質 |
| 過労 | 長時間残業が続く |
| 事故 | 危険な仕事・行動、運 |
| 老衰 | 高齢(長生きした結果) |

- リスクを取る行動(過労、危険な副業、健康を削る働き方)は、稼げる代わりに死にやすくなる
- 健康への投資(運動、人間ドック)で寿命を延ばせる
- 配信・公開を考え、自殺は死因に含めない(プラットフォームの規約上も扱いが難しい)

## イベント

イベントはランダムだが、発生確率は年齢・状態・価値観で変える(例: 人間関係が高いと結婚しやすい、ストレスが高いと離婚しやすい)。多くのイベントに選択肢をつけ、価値観によって正解が変わるようにする。

| カテゴリ | 例 | 主に連動する値 |
| --- | --- | --- |
| ライフ | 結婚、出産、離婚、親の介護、親の死 | 人間関係、年齢、実家の太さ |
| キャリア | 昇進、転職、リストラ、起業、会社の倒産 | スキル、職業、景気 |
| お金 | 投資の当たり外れ、詐欺、臨時収入、宝くじ | 信用、運、投資方針 |
| 健康 | 病気、事故、入院 | 健康、年齢、行動 |
| 社会 | 不況、バブル、増税、物価高 | 時期(ランダム) |

選択肢の例: 「友人に起業へ誘われた。出資する/断る」。挑戦志向なら出資して失敗しても幸福度の下がり方が小さい、など。

起業は会社員などからイベント経由で始める。業種は選ばない。事業は毎月の業績判定で成功・停滞・失敗に分かれ、失敗すると借金を抱えて再就職などに戻る。成功すれば収入は大きいが、ストレスと健康リスクも上がる。

## 世代継承

死亡時に子どもがいれば、上の子が遺産を継いで次の人生を始める。子どもがいなければその家系は終了。

| 引き継ぐもの | 引き継がないもの |
| --- | --- |
| 遺産(相続税を引いた額) | 価値観(子どもごとにプレイヤーが選び直す) |
| 借金(相続放棄も選べる) | 学歴、スキル、職業 |
| 実家の太さ(親の資産から決まる) |  |
| 体質 |  |

リザルトに家系図を出し、何代続いたか・家系の総資産を記録する。親が浪費すれば子は貧乏スタート、という因果が見えるのが配信の見どころになる。

## 配信・公開向け要件

配信の見どころは「初期ガチャ」「分岐の選択」「死亡とリザルト」の3つ。ここが盛り上がるように演出を厚くする。

- 1人生を15〜30分で完走できる速度(倍速、イベントまでスキップ)
- ゲームの状態とイベントをJSONのログとして出力し、既存のAI実況にそのまま流し込めるようにする
- 選択肢を視聴者のコメント投票で決めるモード(後回し)
- シード値: 同じ生まれ・同じ乱数の人生を再現でき、視聴者と同条件で比較できる
- リザルトカード画像: 死因、最終資産、幸福度、人生タイプをまとめてXなどで共有
- 人生ログ: 年表形式で一生を振り返れる(切り抜きの素材にもなる)

## 技術構成とMVPスコープ

サーバーなしの静的サイトにして、運用の手間をほぼゼロにする。職業・イベントなどのデータはJSONで分け、コードを触らずに追加できるようにする。

- フロント: TypeScript + Vite(静的ビルド)
- 保存: localStorage(途中セーブ、過去の人生の記録)
- ホスティング: GitHub PagesかCloudflare Pages
- 乱数: シード付き乱数にして再現性を持たせる
- ロジックと画面を分け、シミュレーション部分だけでテストを回せる構成にする

| フェーズ | 中身 | 規模の目安 |
| --- | --- | --- |
| MVP | 学歴4種、職業5種、価値観4軸、イベント30個、月ターンと年間サマリー、方針設定、手取り近似、死亡判定、リザルト | 1〜2週間 |
| 第2弾 | 家族システム、世代継承、起業、投資・ローン拡充、景気サイクル、リザルト画像 | +2〜3週間 |
| 第3弾 | UIの作り込み、AI実況連携、視聴者投票、イベント100個以上、実績・ランキング | 配信で反応を見て判断 |
